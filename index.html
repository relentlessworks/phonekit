phonekit

Agentic-first phone number parsing, validation, and formatting service. Parse, validate, and format phone numbers in E.164, national, and international formats. Extract country codes, detect line types, and get location info.

Go Single Binary No Database MCP Plain Text API

Quick Start

$ make build && ./phonekit
$ curl "http://localhost:8080/parse?number=%2B14155551234"

Principles

Agent IS the Interface

No UI, no SDK. The API is the product. Every endpoint is designed for an AI agent.

Plain Text by Default

One labeled, grepable line per record. JSON on demand via Accept header or ?format=json.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Single Binary

Go + CGO_ENABLED=0. Zero external dependencies. Deploys as one file.

MCP Connector

Speaks Model Context Protocol at /mcp for chat client integrations.
